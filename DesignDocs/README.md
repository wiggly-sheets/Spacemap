# DesignDocs — Agent-Facing Documentation

This folder holds the agent-facing documentation for the Spacemap project.

## Contents

- [AGENTS.md](./AGENTS.md) — architecture, workflow, and quick reference for agents
- [TASKS.md](./TASKS.md) — roadmap and known issues
- [CONTEXT.md](./CONTEXT.md) — domain glossary
- [adr/](./adr) — architecture decision records (one file per decision)
- [specs/](./specs) — feature/change specifications

## Conventions

- New decisions go in `adr/` as `NNNN-title.md`.
- New specifications go in `specs/` as `NNNN-title.md`.
