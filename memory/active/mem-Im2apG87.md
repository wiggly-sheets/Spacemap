spacemap.xcodeproj/project.pbxproj is generated by `python3 scripts/generate-xcodeproj.py`, which enumerates Sources/ with os.listdir. Any change that adds, renames, or removes a source file leaves the project file stale until the generator is rerun, so Xcode builds fail to see the new files. Run the generator in the same change and commit the project file alongside the sources. Same applies after a file split, where 7 new files were added by splitting GlyphStripPanel.swift.
