# Support

## Where to Get Help

For help using Spacemap, start with the project documentation:

- [README.md](./README.md)
- [CONTRIBUTING.md](./CONTRIBUTING.md)
- [AGENTS.md](./DesignDocs/AGENTS.md)
- [TASKS.md](./DesignDocs/TASKS.md)

If you are reporting a bug, check whether it is already listed in the task tracker or mentioned in the changelog before opening a new issue.

## Best Ways to Report a Problem

Include the following when possible:

- Spacemap version
- macOS version
- Hardware details if relevant, especially Apple Silicon vs Intel
- Exact steps to reproduce
- What you expected to happen
- What actually happened
- Logs, screenshots, or screen recordings if they help explain the issue

If the issue is related to one of these areas, mention it explicitly:

- Accessibility permissions
- Screen Recording permissions
- yabai or skhd availability
- The CLI installer or `/usr/local/bin/spacemap`
- Hotkey handling
- Window dragging or HUD visibility
- Updates or code signing
- Settings category selection, highlighting, or auto-save behavior

## What We Can Help With

Support is best suited for:

- Installation and launch problems
- Configuration questions
- Troubleshooting HUD behavior
- Bug reports with reproducible steps
- Documentation corrections

## What Support Does Not Cover

Support is not the right channel for:

- General macOS support unrelated to Spacemap
- Third-party tool support for yabai, skhd, or Homebrew
- Security vulnerabilities, which should be reported through [SECURITY.md](./SECURITY.md)

## Before Opening an Issue

Try these quick checks:

1. Confirm `yabai` and `skhd` are installed and running.
2. Confirm Spacemap has Accessibility permission.
3. Restart the HUD after config changes.
4. For Settings issues, identify the affected category: Grid, Space Names, Appearance, Behavior, or Debug/Advanced.
5. Check `TASKS.md` for known issues.
6. Check `CHANGELOG.md` for recent behavior changes.

## Tone and Scope

Please keep support requests focused and specific. Clear reproduction steps and environment details make it much easier to help quickly.
